## Troubleshooting

<details>
<summary><strong>🔧 App won't install</strong></summary>
<br/>

- Enable installation from unknown sources in your device settings
- Confirm you have at least 100 MB of free storage
- Re-download the APK — a corrupted file can prevent installation

</details>

<details>
<summary><strong>🛡️ Failing the security check</strong></summary>
<br/>

- HZ Flix requires a non-rooted device to function correctly
- If your device is not rooted and still seeing this error, [open an issue](https://github.com/hzhefaz/hzflix/issues)

</details>

<details>
<summary><strong>📡 Streaming problems</strong></summary>
<br/>

- Verify your internet connection is active and stable
- Try switching to a different streaming provider within the app
- Clear the app cache via your device's App Settings
- Restart the app and try again

</details>

<details>
<summary><strong>💾 Downloads not working</strong></summary>
<br/>

- Ensure storage permission is granted in App Settings
- Check that sufficient storage space is available
- Confirm your internet connection is stable before starting a download

</details>
